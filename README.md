# Ripple Daily

Daily AI-voiced podcast of Ripple's top 10 India market stories (hosts S × P, 7–10 min, English).

**Flow:** the scheduled "Ripple Daily podcast" task (8:07 IST) writes `episodes-src/<date>.json` from the Ripple Feed and pushes it here → the **Build episode** action checks the script, voices it with ElevenLabs Text to Dialogue (free, open-source Kokoro voices: S = af_heart, P = am_michael; speaker codes stay SU/PRI; set tts.engine to "elevenlabs" in config.json to switch back to Hope + Mark), masters the MP3, and updates `feed.xml` → GitHub Pages serves the feed → Spotify picks up the new episode.

- `config.json`: show metadata and voice IDs (not secret).
- Secret `ELEVENLABS_API_KEY`: only needed if tts.engine is "elevenlabs" (repo Settings → Secrets and variables → Actions).
- `scripts/check_script.py`: guard rails (speakers, length, disclaimer, no buy/sell, every number traceable to the Feed).
- Episodes older than 180 days drop out of the feed.

## Brand standard
- Logo: the **R.** mark, a white "R" with a square violet full stop, on black.
- Wordmark: "Ripple" in white, "Daily" in violet (#8B5CF6). The R. square uses the same violet.
- Cover and every episode's artwork use `cover.jpg`, generated by `scripts/make_cover.py`. Change the brand there, never by hand.
